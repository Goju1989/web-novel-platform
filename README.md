## التقنيات المستخدمة

### Backend
- Node.js + Express.js
- MongoDB
- JWT Authentication
- Stripe/PayPal Integration

### Frontend
- React + TypeScript
- Tailwind CSS
- Redux Toolkit
- Axios

### Infrastructure
- Docker
- GitHub Actions (CI/CD)
